# GeoIP database (optional)

Put **GeoLite2-City.mmdb** here to enable the attack map (Command Center → Peta Serangan).
Download it from https://www.maxmind.com/en/geolite2/signup with a free MaxMind account (their licence does not
allow redistributing it, so it is not included). The file is read locally; no address is ever sent online.
Restart is not needed: the backend opens the file on the next request.
